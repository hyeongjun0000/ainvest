# AInvest
# 2026 - 1 OSS Project

📈 AInvest : AI + Invest
Advanced Stock Swing Trading Dashboard with AI Signals

AInvest는 딥러닝 예측 모델과 다각도 기술적 분석을 결합하여 최적의 스윙 매매 타점을 제안하는 인텔리전트 투자 대시보드입니다. 단순히 차트를 보여주는 것을 넘어, 현재 시장이 '롱(Long)'인지 '숏(Short)'인지에 따른 맞춤형 AI 매매 전략을 생성합니다.

Tech Stack
Framework: Streamlit (UI/UX)
Data Source: yfinance (Market Data & Info)
Analysis: Pandas, NumPy (Technical Indicators)
OS: macOS Optimized (Based on Developer Env)

* Disclaimer
본 프로그램은 투자 참고 목적으로 제작되었으며, 모든 투자 결정에 대한 책임은 사용자 본인에게 있습니다. 과거의 수익률이 미래의 수익을 보장하지 않습니다.
